# Bài giới thiệu v1.3.0

Cùng một nội dung, hai ngôn ngữ:

- `vi.md`: tiếng Việt.
- `en.md`: tiếng Anh.

Ảnh dùng chung ở `docs/images/` (`screenshot-vi.jpg`, `screenshot-en.jpg`); khi đăng lên một trang khác, tải ảnh lên đó rồi thay đường dẫn `../../images/…`. Phần "Hướng phát triển" là dự định, chưa có ngày; sửa lại nếu lộ trình đổi trước khi đăng.
