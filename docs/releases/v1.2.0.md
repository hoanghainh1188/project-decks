Sheafly 1.2.0 makes project files feel at home on your computer: double-click to open them, find them again under Open Recent, and run the same Mac build on Intel and Apple Silicon. Scheduling and the file format are unchanged from 1.1.0.

## What's new

- **Double-click to open.** `.sheafly` files, and `.pdproj` files from ProjectDesk, now open in Sheafly from Finder or Explorer. If Sheafly is already running, the file opens in that window; unsaved changes are still asked about first. A file opened while Sheafly starts waits until any autosave recovery offer is answered.
- **File → Open Recent.** The last ten projects you opened or saved, with **Clear Menu**. A file that has been moved or deleted is removed from the list, and Sheafly tells you.
- **One Mac app for Intel and Apple Silicon.** The macOS `.dmg` is now a universal build.
- **Content security policy.** The app window only runs Sheafly's own code, which hardens it against injected content.

## Install

| System | File |
|---|---|
| macOS (Apple Silicon and Intel) | `Sheafly_1.2.0_universal.dmg` |
| Windows | `.msi` or `-setup.exe` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

The installers are **not code-signed** yet:
- **macOS:** try to open Sheafly once, then go to **System Settings → Privacy & Security** and click **Open Anyway** (since macOS 15, right-click → Open no longer works for unsigned apps). If macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Sheafly.app`.
- **Windows:** if SmartScreen asks, choose **More info → Run anyway**.

After installing, double-clicking a project file may still open the previous app it was associated with. Choose Sheafly once with **Open With** (macOS: Get Info → Open with → Change All; Windows: Open with → Always).

## Files

The file format is unchanged: projects from 1.0.0 and 1.1.0 open as they are, and 1.2.0 files open in 1.1.0.

## Known limitations

- The interface is in English and Vietnamese only.
- `.mpp` files cannot be read; use MSPDI (`.xml`) to exchange projects with Microsoft Project.
- The installers are not signed or notarized.
- One user, one window; no dark mode yet.
- On Linux, whether double-click opens a project depends on the desktop environment picking up the MIME type.
