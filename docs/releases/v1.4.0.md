Sheafly 1.4.0 answers the question a single finish date hides: *how likely are we to make it?* Give tasks a low and high effort, and the new Forecast view runs the project a thousand times to show the chance of finishing by each date and the tasks most at risk. This release also lets you zoom the timeline and resize the sheet, groups the macOS menus, and fixes money fields that could save a typed amount as 0.

## What's new

### Finish forecast
- **Effort ranges.** Each task can have a low and a high effort, in the inspector's new Estimate group or in optional sheet columns (View bar → Estimate columns). Fill-down, copy and paste, and table import carry them.
- **Forecast view.** View → Finish Forecast shows the project finish as scheduled, once leveled, and at 50%, 80% and 90% chance. A chart shows how the finish dates spread over the runs, and a table lists the tasks to watch: deadlines least likely to be met first, then tasks that are often critical. Click a task to open it on the Gantt.
- **Forecast columns.** Finish P50, Finish P90 and On time can sit in the task sheet (View bar → Forecast columns).
- **Tasks that slip together.** Project Information → Forecast picks a custom field whose tasks vary together (an area, a team) and how strongly, plus a share every task has in common.
- **How it works.** The project is leveled once, each person keeps the order of their tasks, and each run samples every task's effort from a BetaPERT distribution. The same project always gives the same numbers. A thousand runs over 5,000 tasks take about a second.

### Timeline and layout
- **Zoom the timeline.** Pinch, or Cmd/Ctrl + scroll, on the Gantt; View → Timescale → Zoom In Timescale, Zoom Out Timescale and Actual Timescale Size (⌘=, ⌘−, ⌘0). The date under the pointer stays in place.
- **Resizable split.** Drag the bar between the task sheet and the Gantt; Sheafly remembers the width. Arrow keys, Home and End work too.
- Labels at the edge of the timescale are no longer cut in half; the Load view's day headers line up with their columns; wide tables in dialogs scroll inside the dialog.

### Menus
- The macOS menus are grouped (Import, Export, Task, Timescale, Project Setup, Leveling, Assigning, Tracking), with SF Symbols beside the items.

### Fixes
- **Money fields.** Costs and rates now show with thousands separators (1,248,000), and a grouped amount you type is read correctly. Before, typing "1,248,000" in a cost field could save 0.

## Install

| System | File |
|---|---|
| macOS (Apple Silicon and Intel) | `Sheafly_1.4.0_universal.dmg` |
| Windows | `.msi` or `-setup.exe` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

The installers are **not signed with a developer certificate** yet:
- **macOS:** try to open Sheafly once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Windows:** if SmartScreen asks, choose **More info → Run anyway**.

## Files

Sheafly 1.4.0 opens every project from 1.0.0 to 1.3.0. **A project saved with 1.4.0 cannot be opened in 1.3.0 or earlier**, because the file format has new kinds of edits (effort ranges and forecast settings). Keep a copy if you still share files with someone on an older version.

## Known limitations

- The forecast keeps each person's order from leveling, correlates tasks by one field and one common share, and does not vary link lags.
- Effort ranges and forecast settings are kept only in `.sheafly` files, not in MSPDI.
- The interface is in English and Vietnamese only.
- `.mpp` files cannot be read; use MSPDI (`.xml`) to exchange projects with Microsoft Project.
- The installers are not signed with a developer certificate or notarized.
