Sheafly 1.3.0 is about planning work against the people who will do it: say who can do what and when they are available, let Sheafly suggest who takes each task, preview the plan before applying it, and see everyone's load at a glance. It also brings a dark theme, custom fields, table import, and much faster leveling.

## What's new

### Planning by capacity
- **Leveling in milliseconds.** Leveling 5,000 tasks on 500 people now takes about 40 ms instead of 46 s.
- **Leveling order.** Project Information → Leveling sets the order tasks are placed in (start, priority, slack, deadline, duration, ID or a custom field, each ascending or descending).
- **Availability by date.** A resource's Availability… button sets periods with their own units: leave, part time, a later start.
- **Skills and assignment rules.** Project → Assignment Rules… names skills, gives them to people, and lists rules that pick a person or everyone with a skill from a task's custom fields.
- **Assign by rules.** Project → Assign by Rules… suggests people for the unassigned tasks, spread over everyone with the skill. Before you apply it, a preview shows which tasks move, which deadlines are missed and who is still overallocated. Applying it is one undo step.
- **Urgent tasks.** Tick "Interrupts" on a task and leveling lets it go ahead of lower-ranked work in progress, splitting that work around it. The Gantt draws those gaps as dashed boxes.
- **Resource Load view.** A new Load tab shows each person's work against their capacity, by day or week. Click a person to see their tasks.
- **Outside the span.** Filter or highlight the tasks that finish after a date or milestone you pick, or after their deadline.

### Data
- **Import a table.** File → Import Table (CSV, Excel)… reads tasks or people from a CSV or a workbook. You map the columns and see every problem by row and cell before anything changes.
- **Custom fields.** Text, number and choice fields on tasks: sheet columns, an inspector group, filters and grouping, fill-down. They are exported to Microsoft Project as extended attributes.
- **Copy, paste and fill down tasks.** Copy whole subtrees, including assignments and links, between projects. You can also drag split segments on the Gantt.

### Microsoft Project interop (MSPDI)
- **More fields cross over:** deadlines, progress and actual work, costs, editable actual costs, calendar work weeks, and resource availability.
- **Import warnings.** After an import, a sheet lists what was read differently or left out, such as tasks that move from the file's dates.

### Calendars and costs
- **Calendars based on another calendar.** A project holiday reaches every calendar built on the project calendar.
- **Work weeks.** A calendar can have different hours for a span of dates.
- **Hand-entered actual costs,** on tasks and on assignments.
- **Project Information and Working Time.** Project Information shows statistics, and a Working Time dialog edits every calendar.

### Look and feel
- **Dark theme.** View → Appearance follows the system or stays light or dark.
- **macOS: no more "damaged" message.** The app now carries an ad-hoc signature, so macOS offers **Open Anyway** instead.

## Install

| System | File |
|---|---|
| macOS (Apple Silicon and Intel) | `Sheafly_1.3.0_universal.dmg` |
| Windows | `.msi` or `-setup.exe` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

The installers are **not signed with a developer certificate** yet:
- **macOS:** try to open Sheafly once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Windows:** if SmartScreen asks, choose **More info → Run anyway**.

## Files

Sheafly 1.3.0 opens every project from 1.0.0 to 1.2.0. **A project saved with 1.3.0 cannot be opened in 1.2.0 or earlier**, because the file format has new kinds of edits. Keep a copy if you still share files with someone on an older version.

## Known limitations

- The interface is in English and Vietnamese only.
- `.mpp` files cannot be read; use MSPDI (`.xml`) to exchange projects with Microsoft Project.
- The installers are not signed with a developer certificate or notarized.
- One user, one window.
- Skills and assignment rules are kept only in `.sheafly` files (skills also cross MSPDI as a resource text field).
- On Linux, whether double-click opens a project depends on the desktop environment picking up the MIME type.
